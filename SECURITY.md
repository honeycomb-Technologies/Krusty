# Security Policy

## Supported versions

Security fixes target the latest published Mitsuro release. You may be asked to
confirm an issue against the latest version before a fix is prepared.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private security advisory form:

https://github.com/honeycomb-Technologies/Mitsuro/security/advisories/new

Include:

- the affected version or commit;
- the affected app, server route, or component;
- clear reproduction steps;
- the impact you observed;
- a minimal proof of concept when safe.

Do not include real credentials, customer data, or unrelated private
information. We will acknowledge the report, investigate it, and coordinate
disclosure before publishing details.
