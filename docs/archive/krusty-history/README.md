# Krusty Historical Audit Corpus

This folder preserves older planning, audit, tracker, and closure documents that were kept for project history but removed from the main docs surface.

These files may reference:
- the former `apps/pwa/app` web client
- Svelte-era frontend files
- older validation commands such as `bun run check` or `bun run build`

Those references are preserved when they describe historical implementation state. Current operational guidance lives in the main docs, especially `docs/README.md` and `docs/operations/build-and-deploy.md`.
