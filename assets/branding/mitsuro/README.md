# Mitsuro identity assets

Mitsuro is the product identity. Honeycomb Technologies remains the company identity.

## Canonical geometry

The Mitsuro mark is one rounded, point-up cell. Do not rotate it flat-side-up, replace it with a generic sharp hexagon, or repeat it into a honeycomb pattern. The single cell belongs to Mitsuro; the three-cell outline cluster belongs to Hive; the existing ten-cell mark remains reserved for Honeycomb Technologies.

The lowercase wordmark is set from Quadrillion Semi Bold and stored as outlined SVG geometry. Its final `o` keeps the letter's exterior but replaces the ordinary counter with a larger negative-space copy of the canonical rounded cell. The font binary is intentionally not redistributed.

## Files

- `mitsuro-cell-flat.svg`: solid identity mark for normal UI and print use.
- `mitsuro-cell-mono.svg`: current-color vector for themable surfaces.
- `mitsuro-cell-dimensional.svg`: concave cast-black-metal presentation mark.
- `mitsuro-wordmark.svg`: final lowercase outlined wordmark.
- `mitsuro-lockup-horizontal.svg`: mark plus wordmark lockup.
- `mitsuro-hive.svg`: three-cell Hive mode icon.
- `mitsuro-app-icon-master.svg`: full-bleed cast-metal launcher master.
- `mitsuro-app-icon-tinted.svg`: monochrome launcher master.
- `mitsuro-adaptive-foreground.svg`: transparent safe-zone foreground for Android.
- `mitsuro-splash-mark.svg`: transparent fallback mark for the native splash screen.
- `tokens.css`: source color values for design tooling.

## Usage

Use the flat/mono vectors inside the product. The dimensional treatment is reserved for launcher, splash, release, and brand presentation surfaces. Brass is an identity highlight, not a default control color. Mineral violet is the restrained interactive accent. Orange and bright honey yellow are not part of the Mitsuro product palette.
